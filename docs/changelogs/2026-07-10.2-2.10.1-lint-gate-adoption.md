# Slice 2.10.1 — Lint-Gate Adoption (vedge-app + vedge-ui)

Pays the debt carved out of the 2.10 close-out: turn on `[lints] workspace = true` for the two crates
that opted out (`vedge-app`, `vedge-ui`) so the **whole workspace** passes
`cargo clippy --all-targets -- -D warnings`. Stacked on `feature/2.10-phase-2-close-out` (PR #26).
Measured load going in: **459 production deny-errors + ~1,700 pedantic across 55+ files** (~4× the
1.9/2.10 estimate). Spec/plan: the 2.10 spec's pre-authorized escape hatch; contract in
`Phase 3 - Password Generator/00 - Backlog & Carried Debt`.

## Guiding principle — keep every lint that catches a real bug

A green gate that's *honest*, not rubber-stamped. Four-way split:

1. **Hand-fix the crash-risk restriction lints** (`unwrap`/`expect`/`panic`/`indexing`/`unreachable`) in
   production — a panic crashes the CSR app. `.get()`/`?`/`.first()`/fallbacks; never allowed in prod.
2. **`cargo clippy --fix`** collapsed the machine-applicable pedantic bulk (`use_self`, `cast_lossless`,
   `uninlined_format_args`, `map_unwrap_or`, `excessive_precision`, …).
3. **Documented crate-level `#![allow(...)]`** (each with a one-line reason, mirroring the accepted
   `vedge-tauri/src/pdf/emergency_kit.rs` precedent) only for families that are genuine noise for a
   presentation/CSR-WASM crate: bounded non-adversarial color/geometry/pixel **math**
   (`float_arithmetic`, `arithmetic_side_effects`, `cast_*`), `future_not_send` (WASM is
   single-threaded), fire-and-forget `web_sys`/IPC `let_underscore_must_use`, `must_use_candidate`,
   `too_many_lines` (component render fns), and a few `--fix`-resistant style residuals.
4. **`#![cfg_attr(test, allow(restriction))]`** for the inline test modules (both crates have only
   `#[cfg(test)]` mods, no `tests/` dir — one line covers all test-only restriction hits).

## vedge-ui

- `clippy --fix` + hand-fixes to green. Restriction fixes across `data_table/logic.rs`, `pagination.rs`,
  `dropdown_menu.rs`, `color_picker/types.rs` (rgb/hsl parse → `parts.get(n)?`), `date_picker/
  date_utils.rs`, `file_upload.rs`, `password_strength_meter.rs`, `select/component.rs`, `tabs.rs`;
  `theme/scale.rs` index writes → `zip`/`skip().zip` iterators; `input.rs` guarded-`unreachable!()` →
  a benign shared fallback arm.
- Fixed the workspace-chosen individual lints (`clone_on_ref_ptr` → `Arc::clone` on the version-counter
  `Arc`s; `needless_pass_by_value` → by-ref) and the verified-simplifiable bug-catchers
  (`nonminimal_bool` De Morgan, `if_same_then_else`/`match_same_arms` merges).
- Only **2 per-line `#[allow(clippy::indexing_slicing, reason=…)]`** remain — the provably
  `% option_count` modulo-indexed `radio_group`/`segmented_control` keydown loops.
- Intentional exact float compares (max-channel RGB→HSV selection, `val == val.trunc()` integer check,
  HSL 0/1 edge guards) → documented `float_cmp` allow (verified not bugs). **70 lib tests** pass.

## vedge-app

- Same approach. Removed **37 unused `I18nLocaleTrait` imports** (`unused_imports` is deny). Restriction
  fixes: `app.rs`'s theme-derive `expect` → a logged `fallback_tokens` degrade (a `#[component]` can't
  return `Result`, and the branch is unreachable on the seeded valid default); playground
  `NaiveDate::from_ymd_opt(...).unwrap()` → `.unwrap_or(NaiveDate::MIN)`.
- The macro-generated `include!("i18n.rs")` (a single-line `pub mod i18n { … }`, regenerated by
  `build.rs` each build → not editable in place) is wrapped in an **allow-scoped `mod i18n_generated`**
  (scopes its `expect`/`unwrap`/`dead_code`/`match_same_arms`) and re-exported so `crate::i18n::*` still
  resolves.
- **Dead-code sweep:** deleted the superseded unused `api::*` wrappers
  (`vault::{search,by_tag,by_folder,by_domain,is_unlocked}`, the pre-`_status` `recent::*`,
  `settings::{delete,list,get_theme}`, the bytes-based `emergency_kit`/`document` pairs) and the
  fully-unused `api::{device,maintenance,recovery}` modules; **kept** `api::password` (Phase 3) and
  `api::entry::{restore_entry,hard_delete_entry}` (Trash-UI backlog) with refreshed
  `#[allow(dead_code, reason=…)]`. **86 bin tests** pass.

## Tooling

- **`mise.toml`**: `lint` is now a single whole-workspace pass
  (`cargo clippy --workspace --exclude vedge-e2e --all-targets -- -D warnings`), replacing the old split
  (backend-strict + vedge-app `--no-deps` + the informational `lint-ui`, now removed). `ci` inherits it.
