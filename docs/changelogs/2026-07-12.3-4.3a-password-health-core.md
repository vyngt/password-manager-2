# Slice 4.3a — Password Health (core + wire)

The backend half of Password Health: the vault-wide **secret scan** (weak / reused
/ old), the `secret_changed_at` write-path, and the extracted decrypt helper —
callable end-to-end via IPC. The `/v/health` **UI + `api::health` wrapper ship in
4.3b** (a wrapper with no caller now would be dead code). Spec:
`.../Phase 4 - TOTP & Security Hygiene/Specs/4.3 - Password Health`.

## What shipped

### `vedge-core` — the scan, the stamp, the helper
- **`domain/vault/health.rs`** (NEW): the secret-field taxonomy (`SecretField` +
  a **split `WeakPolicy`** — `const fn weak_policy()`, exhaustive, pinned by
  `weak_policy_is_total`), the report types (`Finding`/`FindingKind`/`HealthReport`/
  …), `secret_fields` (every secret-bearing field per payload; `Login.totp_secret`
  **excluded**), `user_inputs` (name/username/URL host for zxcvbn), and
  `secrets_differ` (the age-bump gate).
- **`domain/vault/health/scoring.rs`** (NEW): the **zxcvbn** wrapper (v3.1.1,
  `default-features = false`) — a 0–4 score capped at `MAX_SCORED_LEN`, with the
  documented, bounded module-level lint-allow (the `entropy.rs`/`emergency_kit.rs`
  precedent).
- **`application/vault/use_cases/scan_health.rs`** (NEW): the **audit-silent bulk
  scan**. Decrypts one entry at a time (peak plaintext = one payload), keyed-HMAC
  reuse grouping (per-scan random key; the digest never leaves core; findings carry
  a `group: u32`), weak-scoring only credential fields (exemptions **counted**),
  per-entry age, and exactly **one** `HealthScanned` audit row (mirroring
  `Exported`). Skips trashed + `Unknown`.
- **`secret_changed_at`** on `CommonMeta` (additive, serde-default, **schema stays
  1**), owned by `create_entry` (stamp on create) / `update_entry` (bump iff
  `secrets_differ`, else carry forward). The DTO never carries it
  (`common_meta_from_dto = None`); `entry_history`'s `UI_META` excludes it.
- **`refs::decrypt_row_with_dek` + `decrypt_row_payload`** (NEW): the canonical
  `entry_aad → decrypt → parse` triplet, extracted from the 5 read/update-path
  copies (`get_entry`/`copy_field`/`reveal_totp`/`unlock_vault`/`update_entry`) —
  side-effect-free, so the bulk scan reuses it. `update_entry`'s decrypt is now
  **unconditional** (it needs the old payload for both the TOTP carry-forward and
  the age diff).
- `AuditAction::HealthScanned` (enum + `as_str` + the silent `parse` arm).

### `vedge-ipc` / `vedge-tauri` — the wire
- `vedge-ipc/src/health.rs` (NEW): `HealthReportDto`/`FindingDto`/… — **derivatives
  only** (`SecretFieldDto::EnvVar` carries the key, reuse a `group` ordinal).
  Adjacently-tagged enums; added to the **wasm wire test** (`wire_wasm.rs`).
- `vedge-tauri`: `dto/health.rs` converter, the `scan_health` command, audit
  totality **16 → 17**, and the `common_meta_from_dto = None` landmine (pinned).

## Decisions & self-review outcomes

A `/code-review high` pass (8 finder angles) drove several changes:
- **Age is 2-tier (`secret_changed_at` Exact, else `created_at` Estimated) — the
  history-based middle tier was dropped.** The review found it (a) attributed age
  to `live.updated_at`, which metadata mutations bump — *reintroducing* the exact
  pollution `secret_changed_at` exists to avoid (a false-negative "Old"); (b) held
  up to 21 un-zeroized history payloads, breaking the "peak = one payload"
  guarantee; and (c) duplicated the taxonomy as a string list. `created_at`
  over-reports staleness for a pre-4.3 rotated-then-untouched entry, self-healing as
  it's edited. **[DRIFT from spec §5 — the 3-tier model.]**
- **Reuse is cross-entry only** (a secret in two fields of one entry is not
  "reused"), **skips empty secrets** (two blank passwords aren't reuse), and has a
  **deterministic** group ordinal (`SecretField: Ord`, total-order sort).
- **`secrets_differ` compares the sorted multiset of secret *values*** — so an
  env-var reorder or key-rename (the key isn't secret) doesn't falsely bump the age.
- `url_host` **reuses `registrable_domain`** (no parser drift); `ts_to_string` uses
  the `dto::common` seam.
- **No-secret / no-digest egress: verified end-to-end** (finder C).

**Accepted (not bugs):** `update_entry` no longer "self-heals" a corrupt row by
blind re-save (correct fail-safe); TOTP enrol/clear doesn't bump password age (spec
intent). **Backlog:** extract a shared HMAC-SHA256 helper (3 copies); route the 6
metadata-mutation decrypt sites through the helper (a distinct
decrypt→mutate→re-encrypt family).

## Security
The scan returns **only non-invertible derivatives**; the reuse digest never leaves
`scan_health` (findings carry a `group` ordinal). `SecretFieldDto::EnvVar` holds the
variable key, `LoginRecoveryCode` an index. Pinned by `reuse_never_emits_digest`
(core) and `health_dtos_carry_no_secrets` (ipc).
