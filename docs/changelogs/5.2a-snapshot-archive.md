# Slice 5.2a — Snapshot + Archive

The first of Phase 5's three backup/restore PRs. Ships the **live-safe snapshot +
`.vbk` archive** half: a vault can now be backed up without a forced lock, into a
self-describing, integrity-checked container. The journaled restore (5.2b) and the
rollback baseline + Backup tab (5.2c) follow.

Spec: `.../Phase 5 - Data Safety & Recovery/Specs/5.2 - Backup & Restore` (PR 5.2a).

## What shipped

1. **WAL pinned (Decision ②).** `VaultDbConnection::open` now issues
   `PRAGMA journal_mode=WAL` after connect, before migrations — it was never pinned
   in the vault's whole life. `journal_mode` is persistent (file-header), so
   existing vaults flip on their next open. Backup correctness (a live
   `VACUUM INTO`) assumes WAL.

2. **`backup_vault` use case (core).** Snapshots the `.vdb` via **`VACUUM INTO`**
   through the existing sea-orm connection (Decision ①: **no `rusqlite`** — the
   `libsqlite3-sys links="sqlite3"` single-version rule + the `unsafe_code` deny
   forbid it), copies every `*.blob` from the `.vedge_blobs/` **directory** (source
   of truth, not the index), and tars them with a `manifest.json` carrying a
   per-file BLAKE3. Atomic `rename` into place; a `.blake3` **sidecar** (Decision ③)
   holds the whole-archive hash. **No KEK/DEK/plaintext in the pipeline**
   (Decision ④ — the archive is ciphertext). Exactly one vault-level `BackupCreated`
   audit row.

3. **The manifest + archive modules (`infrastructure/backup/`).** `manifest.rs`
   (the only new on-disk format — `format_version`, `vault_uuid`, `schema_version`,
   counts, per-file BLAKE3; timestamps as fixed-width RFC-3339 `String`) +
   `archive.rs` (streaming tar write / member extract / `verify_archive` integrity
   gate / streaming `hash_file`). Both pure + DB-free.

4. **Two new port methods.** `VaultRepository::vacuum_into` (bare
   `execute_unprepared` — `VACUUM INTO` can't run in a transaction and fails if the
   dest exists) and `BlobStore::blob_dir` (so the session-scoped use case reaches
   the directory without leaking `derive_blob_root` into the application layer).

5. **Audit vocabulary → 19 (Decision ⑤; the backlog `AUDIT_ACTIONS` trap paid).**
   Added `BackupCreated` + `BackupRestored` (both now; `BackupRestored` is *emitted*
   in 5.2b) — **not** `Exported` (which means readable data left) and **not**
   `Restored` (which means un-trash an entry). New `AuditAction::ALL` const; a shared
   `vedge_ipc::ACTION_NAMES` table that the app's audit filter now **derives from**
   (a compile-time tie — the list can't drift), pinned one-for-one to
   `AuditAction::ALL` by a `vedge-tauri` test. +2 `action_*` locale keys (en + vi).

6. **`backup_vault` command + `BackupReportDto`** (ipc + tauri), registered after
   `run_maintenance`. Derivatives only — counts, hashes, a path, a timestamp; no
   payload or key material crosses the boundary.

## Decisions honored / corrections from the pickup scan

- **No `rusqlite`, no `fs4`, no compression** (Decisions ①/⑥ + research). `tar`,
  `blake3`, and `tempfile` (promoted dev→normal) added; `mise audit` (cargo-deny)
  stays EXIT 0.
- **`VACUUM INTO` via an escaped SQL literal**, not a bound param (that statement
  form doesn't accept one); the dest is an app-controlled temp path.
- **Manifest timestamps are `String`** (`format_rfc3339_millis`) — sidesteps a hard
  dependency on chrono's serde feature and matches the house fixed-width rule.
- The spec's *"`dto/audit.rs` has 3 exhaustive matches"* was stale — the real
  compile gate is core `AuditAction::as_str`; the DTO/app drift is now guarded by
  the `ACTION_NAMES` ↔ `ALL` test + the compile-time array-length tie in the app.

## Tests

`crates/vedge-core/tests/backup_restore.rs` (new): a well-formed round-trip
(3 entries + 1 blob → verify manifest + counts + per-file hashes + sidecar, exactly
one `BackupCreated`, never `Exported`); the `VACUUM INTO` snapshot **opens as a
consistent standalone DB** with the same entry count; a no-documents backup omits
blobs. Plus the WAL-pinned unit test (`connection.rs`) and the pure archive
round-trip / tamper-reject (`archive.rs`).
