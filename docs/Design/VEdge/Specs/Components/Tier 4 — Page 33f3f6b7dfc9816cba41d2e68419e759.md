# Tier 4 — Page

## Overview

Tier 4 Pages are complete application screens. Each page instantiates one or more Tier 3 Patterns inside the application shell and is the only tier that is aware of routing, global state, and application-level context (locked/unlocked vault, selected entry, active category).

**Rule:** Pages do not define layout from scratch — they compose Patterns. If a page requires a structural layout not covered by an existing Pattern, a new Tier 3 Pattern must be defined first.

---

## Page list

| Page | Patterns used | Notes |
| --- | --- | --- |
| Unlock Screen | Unlock Screen pattern | First screen on launch. Z-pattern layout. |
| Main Vault View | Two-panel Shell + Entry List + Sidebar Nav | Core application view. Three-panel with detail on selection. |
| Entry Detail View | Two-panel Shell + Entry Detail Panel | Triggered by selecting an entry row. |
| New Entry Form | Dialog / Two-panel Shell + Form Fields | Modal or inline depending on screen size. |
| Generator | Dialog + Settings Section | Password/passphrase generator overlay. |
| Settings Page | Two-panel Shell + Settings Section × n | Full settings, grouped by category. |
| Onboarding Flow | Unlock Screen pattern (multi-step) | First-run setup: master password, import. |
