# Label

**Status:** Canonical · **Version:** 1.0 · **Layer:** Tier 1 — Atomic

---

## Purpose

The semantic bridge between a text description and the form control it describes. Every visible text label associated with an Input, Select, Checkbox, or any other form control is a Label — not a `<span>`, not a `<p>`, not a `<div>`. The HTML `<label>` element wires the text to its control via the `for`/`htmlFor` attribute, enabling click-to-focus, screen reader announcement, and correct hit-target expansion.

Label is the simplest Tier 1 component in the system. It has no variants, no sizes, and no interactive states of its own. Its complexity comes entirely from its relationship to the control it labels — Label must respond visually to that control's state (focused, errored, disabled) without owning those states itself.

---

## The three ownership boundaries

**The token system decides:** font size, font weight, line-height, color tiers, and all transition timing. Label reads `role.label` tokens — it never sets a raw `font-size` or hex color.

**The Label decides:** which text color tier to use by default, how to render the required indicator, how to render the optional indicator, and how to change color when the associated control reports a status. These are internal visual rules — not exposed as props.

**The consumer decides:** the label text, which control to associate with (`for`), whether the field is required or optional, and `status` to mirror the Input. The consumer never passes a `color` prop.

---

## Anatomy

```
[label root — <label> element]
  [label text]                  ← always present
  [required indicator?]         ← asterisk (*), aria-hidden, 4px left gap
  [optional indicator?]         ← "(optional)" text, 4px left gap

[helper text — separate <p>, lives below Input in FormField]
```

Required and optional indicators are mutually exclusive. A field is one or the other — never both.

---

## Typography role

Label applies `role.label` exclusively. Not configurable.

```
role.label:
  font-size:   var(--text-sm)                 14px
  line-height: var(--text-sm--line-height)    20px
  font-weight: var(--font-weight-medium)      500
  color:       var(--color-text-secondary)    default resting state
```

Color is `text.secondary` at rest — labels are structural context, not primary content. Shifts to `text.primary` when the associated input has focus, driven by CSS `:focus-within` on the parent FormField container. No JavaScript required.

---

## States

Label has no interactive states of its own. It responds to the state of its associated control through two mechanisms: **focus propagation** (CSS `:focus-within` on FormField parent) and **status propagation** (the `status` prop).

### Color by status

| Status | Label color token | When to use |
| --- | --- | --- |
| default (resting) | `--color-text-secondary` | No interaction occurring |
| default (focused field) | `--color-text-primary` | `:focus-within` on FormField parent |
| error | `--color-danger-text` | Input has a validation error |
| success | `--color-success-text` | Input value validated as correct |
| warning | `--color-warning-text` | Input value needs attention |
| disabled | `--color-text-secondary` at `opacity: 0.4` | Associated control is disabled |

Color transitions at `duration-fast` (150ms) `ease-out`. Error state is instant — `duration-instant` (0ms). The user has just submitted; a delayed red label communicates that nothing happened.

### The disabled rule

Disabled state is set on Label via the `disabled` prop — not by reading the associated input's `disabled` attribute from the DOM. The consumer passes `disabled` consistently to both Label and Input.

## Required and optional indicators

### Required indicator

A red asterisk rendered after the label text via `aria-hidden="true"`. The semantic required signal lives on the Input (`aria-required="true"`), not here.

```
[label text] [*]
  color:       --color-danger-text
  margin-left: 4px (--space-1, via gap)
  aria-hidden: true
  font-weight: 500 (same as label — do not bold separately)
```

### Optional indicator

The text "(optional)" in a lighter weight and tertiary color. Only use when the majority of fields are required — making the optional exceptions explicit. Do not use when most fields are optional.

```
[label text] [(optional)]
  color:       --color-text-tertiary
  font-weight: 400 (regular — lighter than label)
  font-size:   var(--text-xs)  12px
  margin-left: 4px (--space-1, via gap)
```

---

## Helper text

Helper text is **not** part of the Label component. It is a separate `<p>` element rendered below the Input inside a FormField. It uses `role.caption`:

```
font-size:   var(--text-xs)   12px
line-height: 16px
font-weight: 400
color:       --color-text-secondary  (default)
             --color-danger-text     (error — instant, 0ms)
             --color-success-text    (success)
margin-top:  4px (--space-1)
```

The gap between Input and HelperText (4px) is tighter than the gap between Label and Input (6px) because HelperText is a continuation of the input's context.

## Props API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `for` / `htmlFor` | `string` | — | **Required.** ID of the associated form control. Wires click-to-focus and screen reader announcements. |
| `required` | `boolean` | `false` | Renders asterisk indicator. Does **not** set `aria-required` — that belongs on the Input. |
| `optional` | `boolean` | `false` | Renders "(optional)" indicator. Mutually exclusive with `required`. |
| `status` | `"default" | "error" | "success" | "warning"` | `"default"` | Mirrors the associated Input's `status`. Drives label color. |
| `disabled` | `boolean` | `false` | `opacity: 0.4`. Must be set by consumer to match the associated Input's `disabled` state. |
| `class` | `string` | — | Layout overrides only: margin. Not for color, font-size, or font-weight. |
| `children` | `Slot` | — | The label text. Plain string in most cases. |

## Token mapping

### Typography tokens consumed

```
--font-sans
--text-sm / --text-sm--line-height      label text (14px / 20px)
--font-weight-medium (500)              label text
--text-xs / --text-xs--line-height      optional indicator, helper text (12px / 16px)
--font-weight-normal (400)              optional indicator
```

### Color tokens consumed

| Element | Token |
| --- | --- |
| Label text (default) | `--color-text-secondary` |
| Label text (focused field) | `--color-text-primary` |
| Label text (error) | `--color-danger-text` |
| Label text (success) | `--color-success-text` |
| Label text (warning) | `--color-warning-text` |
| Required asterisk | `--color-danger-text` |
| Optional indicator | `--color-text-tertiary` |
| Helper text (default) | `--color-text-secondary` |
| Helper text (error) | `--color-danger-text` |

### Motion tokens consumed

```
--duration-fast (150ms)     color transitions (default ↔ focused, success, warning)
--duration-instant (0ms)    error state appearance
--ease-out                  cubic-bezier(0.16, 1, 0.3, 1)
```

## CSS implementation reference

```css
.label {
  display: inline-flex;
  align-items: baseline;
  gap: 4px;
  font-family: var(--font-sans);
  font-size: var(--text-sm);
  line-height: var(--text-sm--line-height);
  font-weight: var(--font-weight-medium);
  color: var(--color-text-secondary);
  cursor: default;
  user-select: none;
  transition: color var(--duration-fast) var(--ease-out);
}

/* Focus propagation — driven by FormField :focus-within */
.form-field:focus-within .label {
  color: var(--color-text-primary);
}

/* Status overrides — take priority over focus */
.label--error   { color: var(--color-danger-text);  transition-duration: var(--duration-instant); }
.label--success { color: var(--color-success-text); }
.label--warning { color: var(--color-warning-text); }
.label--disabled { opacity: 0.4; cursor: not-allowed; }

.label__required { color: var(--color-danger-text); }
.label__optional {
  font-size: var(--text-xs);
  font-weight: var(--font-weight-normal);
  color: var(--color-text-tertiary);
}

/* Helper text — separate element, not part of .label */
.helper-text {
  display: block;
  margin-top: 4px;
  font-size: var(--text-xs);
  line-height: var(--text-xs--line-height);
  font-weight: var(--font-weight-normal);
  color: var(--color-text-secondary);
  transition: color var(--duration-fast) var(--ease-out);
}

.helper-text--error   { color: var(--color-danger-text);  transition-duration: var(--duration-instant); }
.helper-text--success { color: var(--color-success-text); }
.helper-text--warning { color: var(--color-warning-text); }
```

## Composability

Label is not designed to float alone. It lives inside a **FormField** container that owns the vertical spacing between label, input, and helper text, and enables the `:focus-within` CSS that drives the focus color shift.

```
FormField [display: flex, flex-direction: column]
  Label        ← margin-bottom: 6px (--space-1_5)
  Input
  HelperText   ← margin-top: 4px (--space-1)
```

The 6px / 4px asymmetry is intentional — intra-field spacing from the typography-spacing framework.

Label does not read the Input's value, validation state, or focus state from JavaScript. The `:focus-within` pattern reads focus from the DOM directly. When the consumer needs to show an error state, they set `status="error"` independently on Input, Label, and HelperText.

One Label per Input. Never two visible labels for the same field.

## Accessibility requirements

- **Use `<label>` not `<div>`.** The native element is required for browser focus-on-click behavior and screen reader association.
- **`for`/`htmlFor` always required.** Explicit association preferred over implicit wrapping.
- **Required state is semantic, not visual.** Asterisk is `aria-hidden="true"`. Input carries `aria-required="true"`.
- **Error messages are announced.** HelperText uses `role="alert"` or `aria-live="polite"`. Input's `aria-describedby` points to HelperText's ID.
- **`aria-invalid="true"` belongs on the Input** — not on the Label. Label color change is a visual reinforcement only.

---

## Anti-patterns

**Using `<div>` or `<span>` styled to look like a label.** Loses click-to-focus and screen reader association.

**Passing a `color` prop.** Label's text color is status-driven. Use `status` instead.

**Showing both `required` and `optional`.** A logic error. One or the other, never both.

**Trusting the asterisk for accessibility.** `aria-required="true"` on the Input is not optional.

**Interactive elements inside label text.** A link inside a label breaks click-to-focus.

**Using Label as a section title.** Section titles use `role.section-title` on `<h2>`/`<h3>` — never `<label>`.
