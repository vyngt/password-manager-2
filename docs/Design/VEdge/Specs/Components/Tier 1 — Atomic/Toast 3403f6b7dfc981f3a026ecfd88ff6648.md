# Toast

**Status:** Canonical · **Version:** 1.0 · **Layer:** Tier 1 — Atomic

---

## Purpose

Transient notification that reports the outcome of an action. Does not interrupt the user's workflow — requires no response. Appears, lingers, and disappears on its own. Stacking and lifecycle are managed by ToastGroup (Tier 2).

---

## The three ownership boundaries

**The token system decides:** surface color per variant, text color, shadow level, duration values and easing curves for enter/exit.

**Toast decides:** enter/exit animation, dismiss button placement, action button layout, auto-dismiss timer (pauses on hover).

**The consumer decides:** variant, message text, optional action label and callback, optional duration override.

---

## Variants

| Variant | Icon | When to use |
| --- | --- | --- |
| `default` | `Info` | Neutral: "Copied to clipboard", "Settings saved" |
| `success` | `CheckCircle` | Completed: "Entry created", "Export finished" |
| `warning` | `AlertTriangle` | Completed with caveat: "Exported — some fields skipped" |
| `danger` | `AlertCircle` | Failed: "Sync error — try again", "Biometric failed" |

---

## Anatomy

```
[ icon 16px ] [ message ] [ action button? ] [ × ]
```

- Fixed width: 320px
- Min height: 48px. Grows with message text.
- Position: bottom-right, 16px from window edges
- Stacking: managed by ToastGroup. Toast does not know about siblings.

---

## Motion

| Phase | Animation |
| --- | --- |
| Enter | `translateY(8px) → 0`  • `opacity: 0 → 1` over 300ms ease-out (`--duration-slow`  • `--ease-out`) |
| Exit | `opacity: 1 → 0` over 150ms ease-in (`--duration-fast`  • `--ease-in`). No Y movement — exit feels faster than entrance. |
| Auto-dismiss | 4000ms default. Timer pauses on hover (`mouseenter`), resumes on `mouseleave`. |

---

## Props API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `variant` | `"default" / "success" / "warning" / "danger"` | `"default"` | Semantic color and icon |
| `message` | `string` | — | Notification text. Keep under 80 chars. |
| `action_label` | `string` | — | Optional action button text ("Undo", "View", "Retry") |
| `on_action` | `Callback` | — | Called when action button is activated |
| `duration` | `u32` (ms) | `4000` | Auto-dismiss delay. `0` = persistent (manual dismiss only). |
| `on_dismiss` | `Callback` | — | Called on dismiss — auto or manual |

## Accessibility

- `role="status"` + `aria-live="polite"` for `default` / `success` — announced at next pause
- `role="alert"` + `aria-live="assertive"` for `warning` / `danger` — announced immediately
- Live region container is in the DOM at app start (inside ToastGroup), not injected with the Toast
- Dismiss button: `aria-label="Dismiss notification"`
- Action button: receives focus if the user presses Tab while Toast is visible

---

## Do not use

- For errors that block the user from proceeding — use Dialog with an error state
- For information the user must read before continuing — use Dialog
- For persistent status indicators — use Badge or inline status text
- `duration: 0` (persistent) should be rare — a Toast that never disappears defeats its purpose. Use sparingly for critical async failures.

## CSS implementation

```css
.toast {
  display: flex;
  align-items: flex-start;
  gap: var(--space-3);
  width: 320px;
  min-height: 48px;
  padding: var(--space-3) var(--space-4);
  border-radius: var(--radius-lg);
  box-shadow: var(--shadow-lg);
  font-family: var(--font-sans);
  font-size: var(--text-sm);
  line-height: 20px;
}

.toast--default { background: var(--color-surface-4); }
.toast--success { background: var(--color-success-muted); }
.toast--warning { background: var(--color-warning-muted); }
.toast--danger  { background: var(--color-danger-muted); }

.toast__icon {
  width: 16px;
  height: 16px;
  flex-shrink: 0;
  margin-top: 2px; /* optical alignment with first line of text */
}

.toast--default .toast__icon { color: var(--color-text-secondary); }
.toast--success .toast__icon { color: var(--color-success-text); }
.toast--warning .toast__icon { color: var(--color-warning-text); }
.toast--danger  .toast__icon { color: var(--color-danger-text); }

.toast__body {
  flex: 1;
  display: flex;
  flex-direction: column;
  gap: var(--space-1);
}

.toast__message { color: var(--color-text-primary); }

.toast__action {
  font-size: var(--text-xs);
  font-weight: var(--font-weight-medium);
  background: none;
  border: none;
  padding: 0;
  cursor: pointer;
  text-decoration: underline;
  text-underline-offset: 2px;
}

.toast--default .toast__action { color: var(--color-text-secondary); }
.toast--success .toast__action { color: var(--color-success-text); }
.toast--warning .toast__action { color: var(--color-warning-text); }
.toast--danger  .toast__action { color: var(--color-danger-text); }

.toast__dismiss {
  display: flex;
  align-items: center;
  justify-content: center;
  width: 20px;
  height: 20px;
  border: none;
  background: none;
  cursor: pointer;
  color: var(--color-text-tertiary);
  border-radius: var(--radius-sm);
  flex-shrink: 0;
  transition: color var(--duration-fast) var(--ease-out);
}

.toast__dismiss:hover { color: var(--color-text-primary); }

.toast__dismiss:focus-visible {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;
}

/* Enter: slide up + fade in */
@keyframes toast-enter {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}

/* Exit: fade out only — no Y movement, feels faster */
@keyframes toast-exit {
  from { opacity: 1; }
  to   { opacity: 0; }
}

.toast[data-state="entering"] {
  animation: toast-enter var(--duration-slow) var(--ease-out) forwards;
}

.toast[data-state="leaving"] {
  animation: toast-exit var(--duration-fast) var(--ease-in) forwards;
}

@media (prefers-reduced-motion: reduce) {
  .toast[data-state="entering"],
  .toast[data-state="leaving"] { animation-duration: 0.01ms !important; }
  .toast__dismiss { transition-duration: 0.01ms !important; }
}
```
