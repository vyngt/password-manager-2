# Toggle

**Status:** Canonical · **Version:** 1.0 · **Layer:** Tier 1 — Atomic

---

## Purpose

A binary control for settings and preferences. Toggle communicates an immediate on/off state — flipping it takes effect instantly, with no confirmation step. It is the correct component when the action is reversible, the effect is immediate, and the framing is "enable / disable" rather than "agree / select".

Toggle is not a Checkbox. Checkbox represents a selection in a list or a form value to be submitted. Toggle controls a live application setting.

---

## The three ownership boundaries

**The token system decides:** track color (on/off), thumb color, border radius, focus ring, transition duration and easing.

**The Toggle decides:** thumb position (translateX, GPU-composited), how checked state maps to track color, and how disabled mutes the whole component via opacity.

**The consumer decides:** `checked` state, `size`, `disabled`, and `onChange`. The consumer never controls color or animation speed.

---

## Anatomy

```
[toggle-root — label element, click area]
  [track — visual pill background]
    [thumb — white circle that slides]
  [hidden native <input type="checkbox">]
```

The native `<input type="checkbox">` is visually hidden but remains in the DOM for keyboard operability and form semantics. The visual track and thumb are purely decorative — they reflect the input's checked state via CSS.

`role="switch"` on the root overrides the native checkbox role. Screen readers announce "on" / "off" instead of "checked" / "unchecked", which is the correct framing for a toggle.

## Sizes

| Size | Track | Thumb | Use |
| --- | --- | --- | --- |
| `sm` | 32×18px | 14px | Compact settings rows, dense lists |
| `md` | 44×24px | 20px | Default. Standard settings panels. |

Thumb travel distance = track width − thumb size − (2 × thumb inset).

```
sm: travel = 32 − 14 − 4 = 14px
md: travel = 44 − 20 − 4 = 20px
```

Thumb inset is always 2px from the track edge.

---

## States

**Off (default):** Track = `--color-surface-3`, thumb = white (`#ffffff`).

**On:** Track = `--color-primary`, thumb = white. Thumb translates to the right by the travel distance.

**Hover (off):** Track shifts to `--color-surface-4` — one step darker, signals interactivity.

**Hover (on):** Track shifts to `--color-primary-hover`.

**Focus:** 2px solid `--color-focus-ring`, offset 2px. On the root element. Appears instantly (0ms).

**Disabled:** `opacity: 0.4` on the root. `pointer-events: none`. `cursor: not-allowed`. Appears at 0ms.

**Active (pressed):** Thumb stretches slightly — `width: thumb + 4px` — to give physical feedback. 80ms ease-out.

## Motion

```
Thumb translate:
  property:  transform: translateX()
  duration:  var(--duration-fast)  150ms
  easing:    var(--ease-in-out)    cubic-bezier(0.45, 0, 0.55, 1)

Track color:
  property:  background-color
  duration:  var(--duration-fast)  150ms
  easing:    var(--ease-out)

Thumb stretch (active press):
  property:  width
  duration:  var(--duration-micro)  80ms
  easing:    var(--ease-out)
```

`ease-in-out` for the thumb because it's moving from one resting position to another — repositioning within the viewport. `ease-out` for the track color because the color change is a state entrance.

## Props API

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `checked` | `boolean` | `false` | Controlled on/off state. |
| `defaultChecked` | `boolean` | `false` | Uncontrolled default. |
| `size` | `"sm" / "md"` | `"md"` | Physical scale. |
| `disabled` | `boolean` | `false` | Via HTML `disabled` on native input. `opacity: 0.4` on root. |
| `onChange` | `(checked: boolean) => void` | — | Fires on every state change. Receives new checked value directly — not a DOM event. |
| `aria-label` | `string` | — | Required when Toggle has no adjacent visible label. |
| `aria-labelledby` | `string` | — | Points to an external label element's ID. |
| `class` | `string` | — | Layout overrides only: margin, align-self. |

## CSS implementation reference

```css
.toggle { position: relative; display: inline-flex; align-items: center; cursor: pointer; }

.toggle__input {
  position: absolute; opacity: 0; width: 0; height: 0; /* visually hidden, stays in DOM */
}

.toggle__track {
  border-radius: var(--radius-full);
  background: var(--color-surface-3);
  transition: background-color var(--duration-fast) var(--ease-out);
  position: relative;
  flex-shrink: 0;
}
.toggle--sm .toggle__track { width: 32px; height: 18px; }
.toggle--md .toggle__track { width: 44px; height: 24px; }

.toggle__thumb {
  position: absolute;
  top: 2px; left: 2px;
  background: #ffffff;
  border-radius: var(--radius-full);
  transition:
    transform  var(--duration-fast) var(--ease-in-out),
    width      var(--duration-micro) var(--ease-out);
}
.toggle--sm .toggle__thumb { width: 14px; height: 14px; }
.toggle--md .toggle__thumb { width: 20px; height: 20px; }

/* On state */
.toggle__input:checked ~ .toggle__track { background: var(--color-primary); }
.toggle--sm .toggle__input:checked ~ .toggle__track .toggle__thumb { transform: translateX(14px); }
.toggle--md .toggle__input:checked ~ .toggle__track .toggle__thumb { transform: translateX(20px); }

/* Hover */
.toggle:hover:not(.toggle--disabled) .toggle__input:not(:checked) ~ .toggle__track { background: var(--color-surface-4); }
.toggle:hover:not(.toggle--disabled) .toggle__input:checked ~ .toggle__track { background: var(--color-primary-hover); }

/* Active thumb stretch */
.toggle:active:not(.toggle--disabled) .toggle__thumb { width: calc(var(--thumb) + 4px); }

/* Focus */
.toggle__input:focus-visible ~ .toggle__track {
  outline: 2px solid var(--color-focus-ring);
  outline-offset: 2px;
}

/* Disabled */
.toggle--disabled { opacity: 0.4; cursor: not-allowed; pointer-events: none; }

@media (prefers-reduced-motion: reduce) {
  .toggle__track, .toggle__thumb { transition-duration: 0.01ms !important; }
}
```

## Accessibility requirements

- **`role="switch"`** on the root. Announces "on" / "off" — not "checked" / "unchecked".
- **`aria-checked`** reflects the `checked` state. Must be `"true"` or `"false"` — not boolean.
- **Keyboard:** Space toggles. Enter does not toggle (Enter submits forms; Space is the toggle key).
- **Label required.** Either adjacent visible text, `aria-label`, or `aria-labelledby`. A toggle with no label is inaccessible.

---

## Anti-patterns

**Using Toggle for form selection.** If the value needs to be submitted in a form, use Checkbox. Toggle is for live settings only.

**Toggle requiring a Save button.** Toggle takes effect immediately. If a Save button is required, the interaction model is wrong — use a Checkbox or RadioGroup inside a form instead.

**Label on the left, toggle on the right, misaligned.** Toggle + Label should always be composed in a consistent direction. Layout is the parent's responsibility, but the pair must be visually connected.
