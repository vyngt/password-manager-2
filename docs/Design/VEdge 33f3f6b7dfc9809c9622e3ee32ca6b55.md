# Vedge

**Vedge** is a **personal security operations platform** — a privacy-first toolkit for individuals and small teams who need to manage secrets, documents, and certificates without trusting any cloud service.

> *Your private operations layer. Vault, documents, certificates, and secrets — all encrypted, all yours.*
> 

Vedge is not a password manager. It fills the gap between "too simple" (1Password) and "too complex" (HashiCorp Vault) — built for people who take operational security seriously and want everything local-first.

| Tool | What it does | What it lacks |
| --- | --- | --- |
| 1Password / Bitwarden | Password + basic vault | No PKI, no docs, no steganography |
| HashiCorp Vault | Infrastructure secrets | Too complex, not personal |
| Notion / Confluence | Documents | No encryption, cloud-only |
| Keybase | Team crypto | Abandoned |
| **Vedge** | **All of the above, local-first** | — |

---

## What Vedge does

- 🔐 **Secrets vault** — logins, cards, SSH keys, API keys, env vars, documents
- 🎲 **Password generator** — random, passphrase, pronounceable, pattern-based, entropy-measured
- 🖼️ **Steganography** — hide secrets inside images, audio, and text; vault backup in plain sight
- 🏛️ **PKI manager** — build your own CA, manage certs, SSH keys, mTLS; automate via server
- 📄 **Document manager** — write, store, and export technical and classified documents; password-protected PDF/DOCX; vault token interpolation in runbooks
- 📡 **LAN sync** — sync across devices on the same WiFi, zero config, no cloud required
- 🌐 **Browser extension** — autofill, auto-create vault entries on signup
- ⚙️ **CLI + Server** — headless automation, CI/CD cert issuance, scripting
